## 5. 显示页 · 三类工作流

顶部分段：**图片 | 编辑器 | Markdown**（同一「刷到屏幕」出口，输入路径不同）。

### 5.1 图片（默认推荐给「换壁纸」用户）
1. 上传本地图 **或** 填图片 URL  
2. 选择适应：铺满裁切 / 完整显示 / 拉伸  
3. 浏览器量化 → `uploadFrame` → 全刷  
默认 **整屏替换**。不出现图层、不出现 Markdown。

### 5.2 编辑器（排版用户）
添加 / 图层 / 属性为同一套 Editor Chrome；画布优先；刷屏只走顶栏「刷到屏幕」。

**桌面**
- 左窄轨：文字 / 方框 / 二维码（点选即插入并选中）
- 中：1600×1200 预览（可拖拽）
- 右检查器一体：添加条 + 图层列表（上层/下层/删除）+ 选中项属性
- 无画布浮层工具条

**手机 / 平板（半屏底栏）**
- 画布全幅；底栏仅「添加 | 图层」
- 半屏 sheet（约 42–48vh）：添加类型 / 图层列表 / 属性 三态切换
- 添加后或点选图层 → 自动进入属性 sheet；点遮罩或关闭收起
- 未开 sheet 时可完整操作画布

可插入**图片图层**（局部上传，非整屏换图模式）。出口：`renderCanvas`。

### 5.3 Markdown（写字用户）
- 大文本框：手写 / 粘贴 / 打开 `.md`  
- 右侧映射预览（非所见即所得富文本）  
- `#`/`##`→字号；段落/列表→文字层；`![](url)`→走图片管线  
- 出口：解析为 canvas items → 刷屏

## 10. 工作模式与墨水屏更新（固件对齐）

### 工作模式（电源）
| 模式 | 固件映射 | 行为 |
|---|---|---|
| **常开**（默认） | `sleepMin = 0` | 不深度睡眠；Wi‑Fi/MQTT 可一直在线；随时刷屏 |
| **定时刷新** | `sleepMin > 0` + 可选 `wakeUrl` | 醒来 →（可选拉唤醒图全刷）→ 约 2 min 在线窗 → deep sleep N 分钟 |

说明：
- 没有单独的「保活电源模式」。MQTT `keepalive=30s` 是协议心跳，仅在已连接时有效。
- SoftAP/配置活动会取消即将进入的休眠定时器。

### 图片与刷屏（不是视频播放）
墨水屏**保持最后一帧零功耗**，没有连续「播放」；更新都是事件驱动全刷/合成：

| 入口 | API | 流程 |
|---|---|---|
| 图片模式 | `uploadFrame` | 浏览器缩放 + Spectra 6 量化 → 上传帧 → 设备全刷 |
| 编辑器 | `renderCanvas` | 图层 JSON → 设备合成 → 全刷 |
| Markdown | → `renderCanvas` | 解析为文字/图图层后再刷 |
| 定时唤醒 | `wakeUrl` | 醒来 HTTP 拉帧 → 全刷 |
| 测试 | `testPattern` | 六色测试图 |

设备侧不存图库相册；画面来源是「当前帧」+ 可选唤醒 URL。需要轮播时用定时刷新 + 服务端每次换 `wakeUrl` 内容。

## 11. Wi‑Fi 连接 / 持久化 / 重连（定稿）

### 原则
1. **先试连，成功再写 NVS**（不再「保存 → 重启 → 碰运气」）。
2. SoftAP 配网时用 **APSTA**，试连期间热点保持，Web 能直接看到结果。
3. 失败不覆盖已有可用凭据；恢复旧 SSID 并继续退避重连。
4. 断线 **指数退避重连**（1s → 2s → … 封顶 60s），连上后复位。

### 状态（API / UI）
| state | 含义 | UI |
|---|---|---|
| `idle` | 无凭据或未在连 | 灰「未连接」 |
| `connecting` | 用户触发试连 | 橙「连接中…」+ 按钮 loading |
| `connected` | 已拿到 IP | 绿「已连接 · SSID · IP」 |
| `reconnecting` | 曾连上后断开，退避重试 | 橙「重连中…」 |
| 失败 | 试连超时 | 红 toast「连接失败」；表单保留可改 |

### API
- `POST /api/v1/network/setWifiParam` → 试连 → 成功才 `cfg_set_wifi_attr`；返回 `{connected, ssid, ip, state}`；**不重启**
- `GET .../getWifiParam` → `{ssid, isConnected, state, ip}`
- `GET .../getDevInfo` → 增加 `wifiState` / `wifiSsid`

### 重启后
`wifi_sta_start()` 读 NVS 再连；之后同退避重连逻辑。

## 12. Spectra 6 图片转换（防内容破坏）

### 问题
仅用 **最近邻六色量化** 会把连续色调压成色块（posterization），观感像「内容被破坏」。

### 算法选择（业界常用）
| 方法 | 适用 | 说明 |
|---|---|---|
| **Floyd–Steinberg 误差扩散**（已采用） | 照片 / 渐变 | 把量化误差洒到邻像素，远看还原中间色 |
| Sierra-3 / Stucki / JJN | 更平滑 | 核更大，更糊、更慢 |
| Ordered Bayer / Blue-noise | 可预测纹理 | UI 小图形可能出现网纹 |
| 色域校准 + 抖动（epdoptimize 等） | 进阶 | 用实测面板色再匹配，脏点更少 |
| 文字/边缘保护 | UI+图混排 | 硬边用最近邻，照片区才抖动 |

配套：**redmean 感知距离** + **误差封顶**（抑制黄/绿脏点）。

### 实现位置
浏览器侧 `ditherE6ImageData`（`main/www/index.html`）→ `uploadFrame`。设备只收已六色化的 raw 帧。
